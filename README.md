# Dashboard de Vendas em Power BI – Projeto DAX

**Descrição do Projeto**  
Este dashboard foi desenvolvido como parte do curso *Master Power BI – DAX* do Felipe Mafra. O objetivo foi criar um projeto completo de Power BI, aplicando medidas DAX, inteligência temporal e visualizações interativas para análise de vendas de uma empresa fictícia exportadora de materiais escolares.

**Funcionalidades:**  
- +90 medidas DAX aplicadas  
- Análise de KPIs e ranking de gerentes  
- Inteligência temporal para comparação de períodos  
- Clusterização de produtos  
- Dashboards interativos e visuais dinâmicos  

**Habilidades e Tecnologias:**  
Power BI, DAX, Modelagem de Dados, Power Query (M), Análise de Dados, Dashboards Interativos, KPIs, Storytelling de Dados, Visualização de Dados

**Objetivo do Projeto:**  
Simular cenários reais de análise de vendas e gerar insights para suporte à tomada de decisão, aplicando boas práticas de design e visualização de dados.

**Créditos:**  
Projeto desenvolvido no curso *Master Power BI – DAX* (Felipe Mafra). Todo o aprendizado e prática aplicados no projeto são fruto da metodologia e instruções do curso.
